IMPORTANT: WHY LOGIN MIGHT BE FAILING
=====================================
If you receive a "Sign in failed" error, it is highly likely that your local database is not running.

To fix this:
1. Open Docker Desktop (your Docker daemon must be running).
2. Open a terminal in this project directory and start the database container:
   `docker compose up -d`
3. Push the database schema to initialize it (if not already done):
   `npx prisma db push`
4. Now try logging in again!
